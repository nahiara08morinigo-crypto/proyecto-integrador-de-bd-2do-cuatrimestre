# RAMA FERNÁNDEZ: CANVA, DOCUMENTACIÓN, CÓDIGO Y MODELO ENTIDAD RELACIÓN

En esta rama se encuentran los archivos y materiales correspondientes a mi parte del desarrollo del proyecto, y un poco más a lo que aporté.

Acá se reúne el trabajo realizado, incluyendo la presentación en Canva, el código SQL de la base de datos sin las consultas y los dos modelos Entidad-Relación hechos para representar los temas seleccionados.
