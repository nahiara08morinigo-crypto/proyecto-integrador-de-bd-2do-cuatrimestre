# 🏫 Proyecto de Bases de Datos – BD_Secundaria

## 📌 Descripción del proyecto

Este proyecto consiste en el diseño y desarrollo de bases de datos relacionadas con una institución educativa y la información sobre distintas enfermedades.

Se utilizó MySQL para crear tablas, almacenar información y realizar consultas que permitan organizar y administrar los datos.

## 🎯 Objetivos

- Diseñar y crear bases de datos utilizando MySQL.
- Organizar información de una institución educativa.
- Crear tablas para almacenar datos de alumnos, profesores y personal escolar.
- Incorporar información mediante instrucciones INSERT.
- Realizar consultas SQL para buscar, ordenar y contar información.
- Diseñar diagramas entidad-relación y modelos relacionales.
- Aplicar los conocimientos aprendidos durante el cuatrimestre.

## 💻 Desarrollo del proyecto

El proyecto se dividió en dos partes principales:

### 🏫 1. Base de datos de la escuela

Se desarrolló una base de datos llamada **BD_Secundaria**, destinada a organizar la información de una institución educativa.

Se crearon las siguientes tablas:

- Escuela.
- Directivos.
- Profesores.
- Alumnos.
- Auxiliares.
- Preceptores.
- Establecimiento.
- Aulas.
- Laboratorios.
- Persona.

También se agregaron registros y se realizaron diferentes consultas SQL para obtener información específica.

### 🦠 2. Proyecto de enfermedades

Se trabajó con información sobre tres enfermedades:

- Dengue.
- COVID-19.
- Gripe A.

En esta parte del proyecto se realizaron tres actividades principales:

**Explicación de enfermedades**

Investigación y explicación de las características del dengue, COVID-19 y gripe A.

**DER de enfermedades**

Diseño del diagrama entidad-relación para representar la información de las enfermedades.

**Modelo relacional de enfermedades**

Creación y organización de las tablas correspondientes al modelo relacional de enfermedades.
